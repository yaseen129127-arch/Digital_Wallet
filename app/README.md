Digital Wallet Backend

A backend system for a digital wallet built with Python, SQLAlchemy, PostgreSQL, Alembic, and Docker.

The project focuses on building a reliable financial transaction system with a clear database structure, database migrations, accounts, transactions, ledger entries, and external payment operations.

Project Goals

The main goals of this project are:

Build a backend for a digital wallet.
Manage users and wallet accounts.
Support multiple currencies.
Record financial transactions.
Maintain a double-entry-style ledger.
Integrate external payment providers.
Use PostgreSQL as the primary database.
Use SQLAlchemy for database models and database access.
Use Alembic for database schema migrations.
Keep database changes version-controlled and reproducible.
Focus on correctness and data consistency before scalability.
